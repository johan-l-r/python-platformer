# Movement
Today I worked on the logic behind the movement of the player in both the X and Y axis. This wasn't that hard since Pygame provides the input detection system and the only thing we need to do is check for the specific keys that make the player move when pressed: 

## horizontal movement 
To move the player in the X axis was easy, I just had to change the direction when either the A or D keys were pressed, multiply the direction with the speed and update the rect's X position: 
```python
def move(self, keys): 
  self.direction.x = 0

  if keys[pg.K_a]: 
    self.direction.x = -1
  if keys[pg.K_d]: 
    self.direction.x = 1

  self.position.x += self.SPEED * self.direction.x
  self.rect.x = self.position.x
```
Oh! And don't forget to set the direction to zero every frame so the player only moves when the keys are pressed.

## Vertical movement 
This is where things get interesting, because moving horizontally depends on whether the desired key is being pressed or not. However, jumping is a different story, because the action depends on two things: the player being on the ground, and the gravity. 

But first, I'd like to show you my first implementation of the jumping logic: 

```python 
def jump(self, keys): 
  if keys[pg.K_SPACE] and self.is_on_ground: 
    self.is_on_ground = False
    self.direction.y = -1

    self.vectical_speed = self.JUMP_FORCE

  if not self.is_on_ground: 
    if self.direction.y == -1: 
      self.vectical_speed -= self.GRAVITY

      if self.vectical_speed <= 0: 
        self.direction.y = 1
        self.vectical_speed = 0
    
    if self.direction.y == 1: 
      self.vectical_speed += self.GRAVITY

  else: 
    self.direction.y = 0
    self.vectical_speed = 0

  self.position.y += self.vectical_speed * self.direction.y
  self.rect.y = self.position.y
```
